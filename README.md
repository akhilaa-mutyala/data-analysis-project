#  Titanic Data Analysis Project

## About
This project performs Exploratory Data Analysis (EDA) on the famous Titanic dataset to find patterns in passenger survival using Python.

##  Objective
To analyze which factors affected passenger survival on the Titanic such as gender, age, and ticket class.

##  Key Findings
- Only 38% of passengers survived overall
- Women had 74% survival rate vs men only 19%
- 1st class passengers survived more than 3rd class
- Higher ticket fare = better chance of survival
- Most passengers were aged between 20-40 years
